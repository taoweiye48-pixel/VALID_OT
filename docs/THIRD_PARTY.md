# Third-party methods

The primary VALID-OT analyses use the dependencies listed in
`code/requirements-v1.3-core.txt` and `code/protocol/requirements.lock.txt`.

The optional PASTE/PASTE2/3d-OT comparison scripts are retained as wrappers and
configuration records, but their local vendor copies and virtual environments
are not redistributed in this repository. The exact archive identity and
technology requirements used by the analysis are recorded in
`code/protocol/frozen_config.json`. Users should obtain the corresponding
upstream source from its official repository or archive, retain its original
license, and install it separately before running the optional comparison.

No third-party source has been relicensed by VALID-OT.
