# Protocol Amendment 008: v1.2 数值容差与检查点复用

- 冻结时间：2026-07-16T16:41:34+08:00
- 新协议：`valid-ot-v1.2-epsilon025-tol1e8-2026-07-16`
- 配置 SHA256：`7cedfad082ff4ee66b5a2564f403909f4d7dcf2ca81c49c2bce9eb44b55c40a8`
- ε：保持 `0.25`
- Sinkhorn/边际数值容差：由 `1e-9` 调整为 `1e-8`

## 修改原因

v1.1 在 E1 的 15/15 验证通过后，于 E4/E5 的
`Stereo-seq_base2_rigid_seed1__balanced_ot` 首次触发数值门禁。无落盘诊断复算显示，
失败解的最大行/列边际 L1 残差为 `1.3304e-9`，仅略高于冻结的 `1e-9`，且远低于
新的 `1e-8` 上限。调整依据仅为数值残差与双精度稳定性，不依据 E4/E5 聚合科学效果。

## 检查点复用规则

1. v1.1 已完成的 617 个任务均在更严格的 `1e-9` 求解与验收设置下完成，视为满足
   v1.2 的 `1e-8` 上限，直接复用，不重算。
2. 唯一的 `FAILED_NUMERIC` 任务必须在 v1.2 下重新计算，不能只修改其状态文件。
3. 其余 582 个未运行任务按 v1.2 新设置计算。
4. ε=0.1 的 legacy 检查点继续隔离，禁止复用。
5. 最终汇总必须包含恰好 1200 个状态为 `COMPLETED` 的活动检查点；任一新数值失败仍立即停止。

## 可比性说明

复用任务的实际精度比 v1.2 要求更严格，因此属于嵌套容差下的合格结果。科学终点、数据、
随机种子、方法、扰动、ε 和统计门禁均未改变。最终报告必须披露 617 个严格容差复用任务和
583 个 v1.2 新计算任务，不将本次修改描述为原始 v1.1 的无修改确认性结果。
