# Protocol amendment 001: entropic epsilon

**时间**：2026-07-16，E1数值验证期间，读取任何D1/D2科学结果之前。  
**修改**：主 `epsilon` 从 `0.05` 改为 `0.10`；`0.05` 保留为E7预定义稳健性档位。  

## 原因

在完全合成的 `n=64/128` E1测试中，balanced Sinkhorn 在 `epsilon=0.05`、4,000次迭代后边际L1仍约为 `1.7e-6` 至 `1.8e-6`，未达到冻结的数值要求。`epsilon=0.10` 在约310次迭代内达到 `1e-9` 更新容差及低于 `1e-9` 的边际误差。该修订提高数值可验证性，并显著降低后续真实规模计算成本。

## 不受影响的内容

- 数据、pair和标签选择规则；
- `I_EXPR`、`I_SPATIAL` 干预定义；
- 内部忠实性和外部效度主终点；
- 方法集合、统计层级和全部Gate；
- 任何科学结论（修订时尚未产生）。

## 同时修正的测试错误

E1初版错误地要求UOT总运输质量等于1。UOT按定义允许质量松弛，修订后仅检查非负、有限、收敛和重复一致性；balanced OT、row-softmax、PASTE及PASTE2仍检查其对应总质量约束。
