# Data and code availability draft

The analysis uses public spatial-transcriptomics resources whose upstream identifiers, archive metadata, checksums, selected pairs, and processing decisions are recorded in `01_manifest`. Derived pair files, task-level response arrays, summary tables, decision JSON files, code, frozen environments, and figures are indexed by `V1_3_ARTIFACT_MANIFEST.tsv`.

Before public deposition, the authors will verify the redistribution terms of each upstream dataset. If raw archives cannot be redistributed, the release will provide acquisition scripts, checksums, processed-data provenance, and derived results without duplicating restricted files. The VALID-OT code is released under BSD-3-Clause; a permanent repository DOI will be inserted after the tagged release is archived.
