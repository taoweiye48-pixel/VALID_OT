# Licence selection required before public release

The repository is intentionally staged without inventing an author-approved
licence. Before making the GitHub repository public, choose an OSI-compatible
software licence (for example BSD-3-Clause, MIT or Apache-2.0), add its
standard full text as `LICENSE`, and make the same choice in the manuscript's
Code Availability statement.

Third-party datasets and optional PASTE/PASTE2/3d-OT code retain their
upstream terms; the VALID-OT licence must not be applied to them.
